# Deferred Suggestions

These ideas are intentionally outside Task 10 and can be requested later.

## LLM suggestion layer

Use an LLM to suggest—never automatically save—the client, campaign, action type, urgency, meeting details, and vendor-search requirements extracted from a sentence. The user should be able to accept, edit, or dismiss each suggestion before saving.

## Follow Up action type

Consider adding a **Follow Up** action type. It would be useful for common business-development work that does not fit a meeting or vendor search, such as checking on a proposal, payment, approval, or client response. A later version could include a recipient, channel (WhatsApp or email), draft message, and reminder.
